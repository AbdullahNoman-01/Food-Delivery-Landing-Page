## ✨ Key Features

### 1. Dynamic Sticky Navbar
- **Transparent-to-Sticky State:** Starts with a moody transparent background overlaid upon the cinematic hero photo, then smoothly transitions to an opaque white sticky navbar with subtle drop shadow on scroll past the top info bar.
- **Smart Viewport Scroll-Spy:** Dynamically tracks viewport reading positions and highlights the active section link with an elegant golden underline (`#c59b27`) and matching text color.
- **Instant Click Feedback:** Navigating via navbar links immediately updates the active indicator without scroll jitter.
- **Mobile Drawer:** A responsive slide-down menu with a hamburger toggle button, clean row dividers, and an integrated **"Order Now"** action button.

### 2. Hero Section
- **Catchy Main Heading:** *"Delicious Food Delivered to Your Door."*
- **Cursive Tagline & Short Description:** Highlighting 30-minute delivery speed, fresh ingredients, and gourmet quality.
- **Dual Call-To-Action:** Quick *"Explore Menu"* anchor link with smooth scrolling and an interactive *"How to Order"* button.
- **Cinematic Photography:** Full-width hero background image styled with a dark radial vignette gradient overlay for text readability.

### 3. Why Choose Us?
- Showcases the 3 core pillars of FoodieExpress with custom SVG icons in dashed circular badges:
  1. ⚡ **Fast Delivery:** Guaranteed doorstep delivery in under 30 minutes with real-time GPS tracking.
  2. 🌿 **Fresh Ingredients:** 100% farm-sourced, organic produce and chef-selected meats.
  3. 💰 **Affordable Prices:** Gourmet restaurant quality at everyday friendly prices with reward points.
- Hover lift card animations with subtle borders and drop shadows.

### 4. Popular Dishes (Menu)
- Three responsive food cards featuring:
  - 🍔 **Signature Smash Burger** — Double Angus beef patties, melted aged cheddar, secret sauce, toasted brioche ($12.99).
  - 🍕 **Artisan Margherita Pizza** — San Marzano tomato sauce, fresh buffalo mozzarella, fragrant basil ($14.50).
  - 🍝 **Creamy Truffle Pasta** — Handcrafted fettuccine, white wine truffle cream, herb grilled chicken ($15.99).
- Star rating badges, preparation time tags, image zoom effects, and interactive **"Order Now"** action buttons.

### 5. About FoodieExpress
- Two-column layout showcasing the kitchen hub and storefront on Dunlo Street.
- High-res culinary photo with a sleek dark gradient overlay banner.
- 3 Outlined circular specialty badges: **Fresh Menu**, **Hearty Dishes**, and **Beverages**.

### 6. Special Offer & Promo Voucher
- Promotional banner: *"Get 20% Off Your First Order!"*
- Interactive Promo Code box displaying **`FOODIE20`**.
- One-click copy with clipboard integration and toast notification.
- "Claim Offer" button and fast link to eligible menu items.

### 7. Interactive Message & Newsletter Card
- Elegant pre-footer card with ambient gold glow backdrop.
- **Dual Tab Switcher:**
  - 💬 **Send Message:** Inquiries form with Name, Email, Message, and paper-plane send button.
  - ✉️ **Subscribe (News):** Instant email subscription for weekly chef specials and discounts.
- Trust highlights: *15-Min Response Guarantee* & *Zero Spam Policy*.
- Smooth inline toast feedback on submission.

### 8. Iconic Floating Card Footer
- **Website Name & Branding:** Prominent FoodieExpress logo box with lightning bolt and official service tag.
- **Social Media Links:** Facebook, Instagram, TripAdvisor, and X (Twitter) with hover scale effects.
- **Story & Contact Badges:** Detailed address pin (18 Dunlo St, Ballinasloe), direct phone hotline (`090 964 4867`), and customer email (`orders@foodieexpress.com`).
- **Floating Orange Card:** Unique rustic schedule card with dotted leader lines for opening hours (Mon–Sat 9AM–4PM) and bold phone orders.
- **Sub-Footer:** Copyright notice (`© 2026 FoodieExpress. All rights reserved.`) and policy links.
- **Scroll-To-Top Button:** Floating golden button with angle-up icon that fades in after scrolling 300px.

## 🚀 Getting Started & Local Setup

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (version 18 or newer) installed.

### 1. Clone the Repository
```bash
git clone https://github.com/AbdullahNoman-01/Food-Delivery-Landing-Page.git
cd "Food Delivery Landing Page"
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Build Tailwind CSS
To compile the Tailwind stylesheet once:
```bash
npm run build
```

To watch for changes during development:
```bash
npm run dev
```

### 4. Open in Browser
Open `src/index.html` directly in your browser or run a local static server:
```bash
npx serve src
```

## 📱 Responsive Breakpoints

The landing page has been tested and optimized across all modern device viewports:

| Device Type | Viewport Width | Layout Behavior |
| :--- | :--- | :--- |
| **Mobile** | `< 640px` | 1-column cards, hamburger drawer, hidden header action button |
| **Tablet** | `640px - 1023px` | 2-column food cards, balanced padding, adaptive typography |
| **Desktop** | `>= 1024px` | Full navigation bar, 3-column dish grid, floating orange footer card |
| **Large Displays** | `>= 1280px` | Centered max-w-7xl containers, generous whitespace, luxury aesthetic |
